# 📘 Atividade com Estrutura de Repetição `while` (JavaScript)

## 📌 Descrição

Este repositório contém uma série de exercícios desenvolvidos utilizando a estrutura de repetição `while` em JavaScript (sem o uso do `do...while`). O objetivo é praticar validação de dados, controle de fluxo e interação com o usuário.

---

## 🛠️ Ferramentas Utilizadas

* Flowgorithm
* Visual Studio Code
* Git e GitHub
* Navegador Web
* JavaScript

---

## 📋 Exercícios

### 1️⃣ Número positivo

O programa solicita ao usuário que digite um número positivo.
Caso o valor digitado seja negativo, o sistema continua pedindo até que um número válido seja inserido.

---

### 2️⃣ Média de notas

O usuário pode inserir notas entre 0 e 10 indefinidamente.
O programa encerra quando um número negativo for digitado e, em seguida, calcula e exibe a média das notas inseridas.

---

### 3️⃣ Total de compras

O usuário informa valores de compras.
Quando o valor digitado for **0**, o programa finaliza e exibe o total acumulado.

---

### 4️⃣ Nome completo obrigatório

O programa solicita o **primeiro nome** e o **sobrenome** separadamente.
Caso algum dos campos esteja vazio, o sistema solicita novamente até que ambos sejam preenchidos corretamente.

---

### 5️⃣ Simulação de saque bancário

O usuário tenta realizar um saque a partir de um saldo inicial armazenado em uma variável.

* Se não houver saldo suficiente, o programa solicita um novo valor.
* O processo continua até que o saque seja possível.
* O programa encerra quando o saldo for **0 ou negativo**.

---

* Utilizar a estrutura `while` para repetição
* Validar entradas do usuário
* Controlar condições de parada
